# Maluku Journal

A minimalist, editorial travel blog inspired by Roadbook.com—built for fast loading and immersive storytelling around Maluku’s archipelago.

## Highlights

- **Immersive hero** with a “Spices & Seas” tone
- **Editorial masonry grid** with refined white space and modular stories
- **Island navigation** for Lease, Banda, and Southeast Maluku
- **Scroll-reveal transitions** with lightweight Intersection Observer
- **Typography pairing**: Playfair Display (headings) + Inter (body)
- **Performance touches**: responsive hero preload + lazy-loaded imagery
- **Editorial metadata** strip with issue/date details + light/dark theme toggle
- **Contact section** with icon links to WhatsApp, email, and Instagram
- **Hero contact bar** with quick icon links
- **Issue archive page** for past editions + floating WhatsApp button

## Quick start

Open `index.html` in a browser. No build step required.

The issue archive is available at `archive.html`.

## Optional local server

If you want a local server for smooth image loading and testing, you can run:

```powershell
npx serve .
```

## Customization

- Update images and copy in `index.html`.
- Adjust palette and layout in `styles.css`.
- Extend filtering or animations in `app.js`.
